# LaunchTrip

AI marketing assistant for Algerian travel agencies. Generates social media posts, promotional emails, and Meta Ads copy in minutes.

## Live Demo


- **App:** [https://launchtrip.onrender.com](https://launchtrip.onrender.com)

## What It Does

1. **Fill in your offer** — destination, hotel, dates, price, transport, and agency identity
2. **AI generates the content** — social media post, promotional email, and Meta Ads copy in parallel
3. **Copy and publish** — content ready for Facebook, Instagram, TikTok, or WhatsApp

## Key Features

- Supports 8 trip types: organized trip, promotion, family, romantic, Omra/Hajj, domestic tourism, long-stay, and flights only
- Generates content in French, Arabic, or both simultaneously
- Built-in Algeria market context extracted from 19+ real agency posts across 5 Algerian cities
- Platform-specific copy for Facebook, Instagram, TikTok, and WhatsApp
- Adjustable content length and hashtag count
- Structured Meta Ads JSON output with primary texts, headlines, descriptions, and CTAs
- All 58 Algerian wilayas available as departure cities

## Tech Stack

- Node.js + Express
- Gemini 2.5 Flash API
- Vanilla HTML, CSS, JavaScript
- Bootstrap 5
- Deployed on Render
